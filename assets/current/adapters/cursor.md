# Project workflow

Read-only inspection may proceed. Explain the scope and risks and get explicit approval before writes or external changes. For small tasks, approve the bounded task once. For large tasks, approve phases. Whole-plan approval covers all listed steps without repeated requests; significant scope or risk changes need a new decision. Preserve existing work, verify changes, and report results briefly.

From the project root, read .ai/README.md and .ai/rules/permissions.md. On resumption, inspect the relevant .ai/tasks record and verify it against Git and the code before continuing.
