## Tracking progress

The [agreed simplification](SIMPLIFICATION.md) defines the current four-phase improvement plan. Phase 1 is approved directly on `main` and consolidates runtime rules. Later phases require approval. Older milestone results below remain historical evidence, not verification of the new flow.

Phase 1 completed on November 18. Full runtime rules now cover the agreed communication, phase approvals, official documentation fallback, UI, test cases, self-review, branch/worktree choice, Git identity, cleanup, skills, and knowledge preservation. Historical manifest templates are unchanged. Type checking and diff whitespace checks passed. The suite passed 42 of 46 tests in the sandbox; four coordination fixtures were blocked by access to the configured Git signing agent. All four passed when rerun with approved access outside the sandbox. No live agent trial or publication was performed. Phase 2 remains awaiting approval.

Phase 2 was subsequently approved and completed on November 18, directly on `main`. The unpublished candidate is v0.4.4. Rules and onboarding skills now support versioned management, conservative legacy enrollment, explicit project-owned exceptions, installed component choices, three-way conflicts, repair, and reversible updates. Added 13 regression cases covering preservation, pins, missing files, partial recovery, legacy backups, invalid journals, and privacy. Type checking, all 59 tests (55 sandbox tests and four coordination tests with approved signing-agent access), package build, offline install, and package smoke checks passed. The diff was reviewed. No commit, publication, or live-agent trial was performed. Phase 3 awaits approval.

Phase 3 was subsequently approved and implemented directly on `main` as the unpublished v0.4.5 candidate. Plain `init` now installs complete rules and selected native onboarding skills, offers tracking and additional references, and can start onboarding after separate confirmation in an interactive terminal. Local-only ignores have preview, tracked-file safeguards, backup, rollback, and recovery. Legacy scripted options and compatibility commands remain supported. Stock native instruction upgrades preserve generated activation links. Type checking and all 72 tests passed (68 sandbox tests plus four coordination tests with approved signing access). Build, offline installation, and package smoke checks passed. Alias fixtures use harmless local programs; authenticated agent trials remain for the owner. No commit or publication was performed. Phase 4 awaits approval.
